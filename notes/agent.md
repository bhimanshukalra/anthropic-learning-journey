### What makes a great agent (crew ai)?

Role playing, focus, tools, cooperation, guardrails, memory

- Role playing - You are a registered financial analyst, give me an analysis of tesla stock.
- Focus - You different agents for different kind of work e.g. a writer agent, a reviewer agent etc.
- Tools - provide minimal amount of tools to an agent to ensure it can perform well
- Collaboration - take feedback, delegate tasks
- Guardrails - AI has fuzzy inputs, fuzzy transformations and fuzzy outputs. It is important to ensure we have guardrails in place to make sure the results are as per the expectation.
- Memory - ability to remember what the agent had done previously, learn from it and do the appropriate next step.

Memory types:

1. Short term - share knowledge/learning across all the agents
2. Long term - stored after execution is complete. It can be used for future tasks. Leads to self-improving agents.
3. Entity - remembers the subjects being discussed e.g. persons, orgs, locations.
